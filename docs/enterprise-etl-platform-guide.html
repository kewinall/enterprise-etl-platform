08 · Security

Repository

Artifact

CycloneDX SBOM、OCI provenance、SHA-256、detached signature。

Runtime

Monitoring

Read-only views、least privilege、Grafana 不直接查 raw audit。

13 · Interview Q&A

面試時最值得講的工程決策

可直接展開作為面試回答提示。

為什麼 Airflow 不直接做 ETL transform？

Airflow 是 orchestration layer；Hop 是 ETL execution layer。這樣能降低 DAG 與 data-processing implementation 的耦合，讓 retry、排程與 pipeline 本身分工清楚。

為什麼 retry 要保存 attempt_number？

如果同一 run 只保留最後 SUCCESS，就會失去第一次 FAILED 的根因與時間軸。每個 attempt 獨立稽核，才能支援 incident review、SLA/SLO 分析與 audit traceability。

為什麼 PROD 不能重新 build？

TEST 驗證的是 artifact X；如果 PROD 又 build 出 Y，就失去「測過的東西就是上線的東西」這個保證。因此 promotion 應基於 immutable image identity / registry digest。

為什麼 Grafana 不直接連 PostgreSQL raw audit？

Observability 應有 least-privilege surface。SQL Exporter 只讀 aggregate views，Prometheus 儲存時序資料，Grafana 只讀 Prometheus，降低 raw audit schema 與 credential 暴露面。

為什麼 RUNNING 不能當 Prometheus counter？

因為 execution 會從 RUNNING 轉成 SUCCESS/FAILED，RUNNING count 可能下降，違反 counter 單調遞增語意。Current state 應用 gauge，final attempt count 才適合 counter。

這個專案最能證明什麼？

不是單一工具熟悉度，而是能把 Data Engineering 的執行、稽核、供應鏈、離線交付、安全與維運觀測串成一條可驗證的 enterprise lifecycle。
