# v0.5.0 — Prometheus, Grafana, SLO & Alerting

## 繁體中文

Enterprise ETL Platform v0.5 將 v0.4 的 audited / immutable ETL platform 擴充為可執行的 observability layer：

- 新增 read-only `etl_observability` PostgreSQL views
- 新增 least-privilege synthetic monitor role
- SQL Exporter 0.24.8
- Prometheus 3.14.0
- Alertmanager 0.34.0
- Grafana 13.2.1
- ETL execution / failure / retry counters
- records-written counter
- stale RUNNING gauge
- last-success timestamp
- average / P95 duration gauges
- 99% ETL success SLO
- error ratio / error budget recording rules
- SLO breach / stale execution / no-recent-success alerts
- Grafana auto-provisioned Prometheus datasource
- Enterprise ETL Operations dashboard
- CI runtime observability smoke test

CI 會灌入 synthetic SUCCESS、FAILED、retry SUCCESS 與 stale RUNNING execution，並實際確認 SLO 與 stale alert 進入 firing，而不是只做 YAML/JSON 靜態檢查。

v0.5 不包含 v0.6 的 deployment/recovery governance hardening。

## English

Enterprise ETL Platform v0.5 adds an executable observability layer to the audited and immutable ETL platform:

- read-only PostgreSQL observability views
- least-privilege synthetic monitoring role
- SQL Exporter 0.24.8
- Prometheus 3.14.0
- Alertmanager 0.34.0
- Grafana 13.2.1
- ETL run/failure/retry counters
- records-written metrics
- stale-running gauge
- latest-success timestamp
- average and P95 duration gauges
- 99% ETL success SLO
- error-ratio and error-budget recording rules
- SLO/stale/no-recent-success alert rules
- provisioned Prometheus datasource and operations dashboard
- executable CI observability smoke test

CI creates synthetic success, failure, retry-success, and stale-running executions and proves the expected alerts actually enter the firing state.

Deployment/recovery governance hardening remains v0.6 scope.
