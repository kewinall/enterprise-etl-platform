# v0.6.0 — ETL Intelligence + Enterprise Delivery Security

## 繁體中文

v0.6 將 Enterprise ETL Platform 從 runtime / audit / observability 擴充至 design-time ETL intelligence 與完整 enterprise delivery security。

新增：

- deterministic Apache Hop / generic legacy ETL parser
- normalized ETL metadata + evidence/provenance
- AI semantic analysis boundary
- sensitive context filtering
- structured/evidence-bound AI output validation
- deterministic fallback
- root .gitlab-ci.yml enterprise reference
- build-once / same-registry-digest TEST→PROD promotion
- CVE applicability / remediation lifecycle
- vulnerability gate、SBOM diff、digest verification、regression evidence
- architecture / security / governance / interactive guide updates

Repository responsibility 仍維持 Enterprise Data Engineering Platform；ETL AI 僅處理 design-time semantics，不處理 runtime incident RCA。

## English

v0.6 adds design-time ETL intelligence and enterprise delivery security while preserving the repository boundary as an Enterprise Data Engineering Platform.

The release includes a deterministic ETL parser, normalized evidence/provenance, an evidence-bound AI semantic layer with fallback, an executable GitLab CI/CD reference, same-digest promotion, and a verifiable vulnerability remediation lifecycle.

Runtime incident RCA remains outside this repository.
