# v0.4.0 — Immutable Image Promotion & Air-Gapped Bundle

## 繁體中文

Enterprise ETL Platform v0.4 將 v0.3 的 audited ETL runtime 擴充為可驗證的 software supply chain：

- 新增 immutable Apache Hop runtime Dockerfile
- ETL project bake into runtime image
- OCI version / revision / source labels
- Build once / promote same image ID
- Candidate → TEST → PROD promotion invariant
- Syft CycloneDX image SBOM
- Docker image offline archive
- Promotion manifest
- SHA-256 checksum
- OpenSSL detached signature
- Offline signature/checksum/load verification
- CI 自動執行完整 supply-chain smoke
- GitHub Release 自動附加 validated offline bundle assets
- Credential 仍維持 runtime injection，不 bake 進 image
- Production signing key 必須由外部受控 secret/HSM 提供

CI 會實際移除本機 candidate/TEST/PROD image references，再由 offline archive `docker load`，並確認 loaded image ID 與原始 candidate 完全一致。

v0.4 不包含 Prometheus/Grafana、SLO 與 alerting；Observability 保留給 v0.5。

## English

Enterprise ETL Platform v0.4 adds a verifiable software-supply-chain layer to the audited ETL runtime:

- immutable Apache Hop runtime image
- ETL project baked into the image
- OCI version/revision/source labels
- build-once promotion across candidate, TEST, and PROD
- CycloneDX image SBOM generated with Syft
- Docker image archive for air-gapped transfer
- promotion manifest
- SHA-256 checksums
- detached OpenSSL signatures
- offline signature/checksum/load verification
- CI supply-chain smoke test
- validated offline assets attached to the GitHub Release
- runtime-only credential injection
- external protected signing-key requirement for production

The CI proof removes the local image references, loads the offline archive, and verifies the loaded image has the same immutable image ID as the original candidate.

Prometheus/Grafana, SLOs, and alerting remain v0.5 scope.
