# v0.8.0 — ETL AI Evaluation / Production Evidence

## 繁體中文

v0.8 將重點從新增 ETL AI Feature 轉向 **Evaluation / Quality / Cost / Latency / Failure / Evidence**。

新增：

- 10 組 synthetic / generic ETL evaluation cases 與 deterministic ground truth
- Parser precision / recall / F1 / exact-match / failure-rate evaluation
- AI structured output、grounding、completeness、factual consistency 與 parser-truth preservation evaluation
- unknown source / target / SQL / dependency / evidence hallucination guard
- invalid structured output validation retry 與 deterministic fallback
- Multi-LLM AI Gateway usage / cost / provider / model / attempts evidence consumption
- per-pipeline / batch / provider-model aggregation與 243 pipeline projection
- Parser-only vs Parser+AI、raw input bytes vs structured context bytes ablation
- JSON / Markdown / Interactive HTML reports
- P2 CI artifact 與 regression tests

限制：

- 所有 public evaluation data 都是 synthetic，不代表真實 production benchmark。
- checked-in baseline 沒有 live Gateway usage，因此 token/cost 為 unavailable；不虛構 provider pricing 或 token count。
- structured unsupported-claim detector 不宣稱是通用自然語言 fact checker。

## English

v0.8 is an evidence-focused release. It adds a repository-owned synthetic ETL evaluation corpus, deterministic parser metrics, semantic contract/grounding checks, structural hallucination rejection, explicit AI failure semantics, Gateway usage/cost evidence consumption, repeatability and input-surface ablation, CI-generated reports, and an interactive evaluation visualization.

No customer data or fabricated production/provider benchmark is included. Provider token/cost values remain unavailable until actually supplied by a live Multi-LLM AI Gateway response.
