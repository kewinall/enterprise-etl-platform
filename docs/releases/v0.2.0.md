## 繁體中文

Enterprise ETL Platform v0.2 將 v0.1 的架構骨架提升為可執行的 **Airflow → Hop Server → Apache Hop pipeline** 整合：

- Apache Hop 升級至 2.19.0
- 新增可執行 `synthetic_customer_daily.hpl`
- 新增 Hop project configuration
- Hop Server 以 Docker Compose long-lived service 執行
- Airflow DAG 透過 authenticated Hop Server REST API 觸發 pipeline
- `RUN_ENV` 由 Airflow 傳入 Hop pipeline
- PR/main CI 實際啟動 Hop Server 並執行 pipeline smoke test
- Release workflow 改為讀取版本專屬雙語 release notes
- 所有資料、Hostname、Credential 與 Schema 均維持 synthetic / generic

本版本刻意不加入完整 PostgreSQL execution audit 寫入、retry/error lifecycle table 與完整 sample ETL persistence；這些屬於 v0.3。

## English

Enterprise ETL Platform v0.2 turns the v0.1 architecture skeleton into an executable **Airflow → Hop Server → Apache Hop pipeline** integration:

- Upgrade Apache Hop to 2.19.0
- Add executable `synthetic_customer_daily.hpl`
- Add Hop project configuration
- Run Hop Server as a long-lived Docker Compose service
- Trigger the pipeline from an Airflow DAG through the authenticated Hop Server REST API
- Pass `RUN_ENV` from Airflow into the Hop pipeline
- Start Hop Server and execute the pipeline in PR/main CI smoke tests
- Make the release workflow consume version-specific bilingual release notes
- Keep all data, hostnames, credentials, and schemas synthetic or generic

Full PostgreSQL execution-audit writes, retry/error lifecycle tables, and persisted sample ETL outputs are intentionally deferred to v0.3.
